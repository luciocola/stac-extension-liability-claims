STAC Extension: Liability and Claims

Comprehensive metadata for imagery quality, legal claims, data quality, and provenance

📋 About This Extension

The Liability and Claims STAC Extension provides comprehensive metadata support for:

🎯 Imagery Quality (NIIRS)

National Imagery Interpretability Rating Scale for standardized quality assessment

⚖️ Legal Claims Tracking

Liability claims, incidents, responsible parties, and resolution status

📊 Data Quality (ISO 19157)

Comprehensive quality reports following ISO 19157-1:2023 standard

🔗 Provenance (W3C PROV)

Complete lineage tracking using W3C PROV-JSON standard

🚀 Quick Start

Add the extension to your STAC Item or Collection:

{
  "stac_version": "1.0.0",
  "stac_extensions": [
    "https://luciocola.github.io/stac-extension-liability-claims/v1.5.0/schema.json"
  ],
  "properties": {
    "liability:niirs": {
      "overall": 6,
      "variants": {
        "visible": 6,
        "multispectral": 5
      },
      "evaluation_method": "giqe4_prediction"
    }
  }
}
